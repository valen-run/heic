## [0.1.0] - Unreleased

### Added
- Initial project scaffolding and modular Rust workspace architecture.
- Modular crates: `heic-core`, `heif-parser`, `heic-decoder`, `image-processing`, `image-encoder`.
- WebAssembly binding crate `wasm`.
- TypeScript package `@valen-run/heic` with typed errors, input handling, and processing limits.
- CI workflows for formatting, clippy, unit tests, and type checking.
- Initial architecture, security, and developer documentation.
