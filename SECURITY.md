# Security Policy

## Reporting Security Issues

If you discover a potential security vulnerability in `@valen-run/heic`, please report it by emailing:

[**hi@valen.run**](mailto:hi@valen.run)

Please do NOT file public GitHub issues for security vulnerabilities.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Security Architecture

See [Security Architecture](docs/security.md) for details on memory isolation, input size and dimension limits, parser sandboxing, and defenses against decompression/allocation denial of service attacks.
